# Safaricom PwnZone CTF 2026 — Writeups

Writeups for all 37 challenges we solved at **Safaricom's PwnZone CTF 2026** (pre-qualifiers, 2–4 October 2026), covering web, cloud, crypto, forensics, mobile forensics, OSINT, reverse engineering, CVE and AI.

Prefer one long read? Start with [`full-writeup.md`](full-writeup.md), which walks through every challenge in order. The per-challenge files below are the same material split up so you can jump straight to the one you're stuck on.

> Flags are per-team and rotate between instances, so the flags in these writeups won't work anywhere. The attack chains are the point.
